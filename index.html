Como configurar o Google Sheets
1
Crie uma planilha no Google Sheets
Abra sheets.google.com, crie uma nova planilha e nomeie as colunas da linha 1: Equipamento, Data, Hora
2
Abra o Apps Script
No menu da planilha, clique em Extensões → Apps Script
3
Cole este código
Apague o conteúdo existente e cole o código abaixo:
function doPost(e) { try { var sheet = SpreadsheetApp .getActiveSpreadsheet() .getActiveSheet(); var dados = JSON.parse(e.postData.contents); dados.forEach(function(item) { sheet.appendRow([ item.numero, item.data, item.hora ]); }); return ContentService .createTextOutput("OK") .setMimeType(ContentService.MimeType.TEXT); } catch(err) { return ContentService .createTextOutput("ERRO: " + err) .setMimeType(ContentService.MimeType.TEXT); } }
4
Implante como Web App
Clique em Implantar → Nova implantação → Tipo: App da Web → Executar como: Eu mesmo → Quem tem acesso: Qualquer pessoa → clique Implantar. Copie a URL gerada e cole no campo acima.
